# hcm202 — Mảnh ghép tư tưởng

Bản thử web ghép thẻ bằng HTML/CSS/JavaScript, không cần cài thư viện. 3 bộ kiến thức, 15 kết nối, lưu tiến trình trên thiết bị và in poster kết quả.

## Chạy
Mở `index.html` hoặc chạy `python -m http.server 5174` trong thư mục này, truy cập http://localhost:5174.

## Deploy Vercel
Import repository, chọn Framework Preset **Other**, không có Build Command, Output Directory `.`.

## Nội dung
Giáo trình Tư tưởng Hồ Chí Minh do người dùng cung cấp là nguồn chính. Chương 5 đối chiếu tr. 99–106. Các mô tả Chương 4/6 trong bản thử cần kiểm tra lại trang nguồn trước bản nộp chính thức. Poster là tổng hợp của dự án, không phải trích dẫn lịch sử. Video là liên kết tham khảo, chưa được thẩm định toàn bộ.
